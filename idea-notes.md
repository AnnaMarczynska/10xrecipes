# 10xRecipes

### Main issue 
Manual search for convenient recipes based on changing criteria such as 
available products and time for cooking may be frustrating and challenging,
forcing to order more expansive and less healthy food.

### MVP
- selecting products based on available list
- selecting time to prepare meal based on available list
- selecting meal type based on available options
- searching through list of available recipes
- adding favourite recipes
- adding, editing and deleting notes for favourite recipes
- adding allergens
- displaying animation of ingredients being added to a pot 
- creating basic user management system

### What is not included
- creating menu for a whole day
- adding onw recipes
- adding own ingredients
- calculating calories of selected recipe 
- sending recipes to another user
- mobile app version (web only)

### Success criteria
- user can find at least one recipe matching selected ingredients, preparation time and meal type
- recipes containing user's allergens are excluded from search results or clearly marked
- user can add and remove recipes from favourites
- user can add, edit and delete notes for favourite recipes
- user's favourites, notes and allergens are saved and available after logging in again
- user can create an account, log in and log out
- ingredient animation is displayed correctly for supported recipes
