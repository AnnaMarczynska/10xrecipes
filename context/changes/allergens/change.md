Add allergen management: profile tracking, recipe warnings, and search filtering

**Decisions made:**

- Recipe allergen data: manual tagging of top recipes MVP + crowdsource post-launch
- Workflow: users add allergens to profile, search excludes/warns about recipes with those allergens
